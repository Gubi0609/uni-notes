# L2 - Fuzzy Logic Control 1

## Flashcards

When is fuzzy logic control useful?::When the system is not fully known/crisp; it handles gradual transitions instead of abrupt switching (e.g., braking distances).

What is a fuzzy set?::A set where elements have degrees of membership in $[0,1]$, described by a membership function $\mu_A(x)\in[0,1]$.

What is a membership function?::$\mu_A(x)$ maps an element $x$ to its degree of membership in set $A$, a value in $[0,1]$.

What is the cardinality of a fuzzy set?::$|A| = \sum_X \mu_A(x)$, the sum of membership degrees.

Union of two fuzzy sets?::$\mu_{A\cup B}(x)=\max(\mu_A(x),\mu_B(x))$.

Intersection of two fuzzy sets?::$\mu_{A\cap B}(x)=\min(\mu_A(x),\mu_B(x))$.

Complement of a fuzzy set?::$\mu_{\bar A}(x)=1-\mu_A(x)$.

What is a linguistic variable?::A variable whose values are words/labels rather than numbers (e.g., Distance, Brake).

What is a linguistic value?::A label describing a degree (e.g., ExtremelyClose, Slam) used as input/output in fuzzy rules.

What is a fuzzy rule and a rule-base?::A rule is "if premise then action"; a rule-base is a collection of such rules.

What is the structure of a fuzzy rule?::if (antecedent/premise) then (consequence/action).

What is the goal of the level controller example?::Maintain water level around 75% by regulating influx via the Level Control Valve.
