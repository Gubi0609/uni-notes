# L7 - Reinforcement Learning - Dynamic Programming

## Flashcards

What is dynamic programming (DP) in RL?::A family of algorithms that compute optimal policies given a complete model of the environment (transition dynamics).

What does policy evaluation compute?::The state-value function $v_\pi$ for a given policy $\pi$ by iterating Bellman expectation updates.

What is policy improvement?::Making the policy greedy with respect to the current value function: $\pi'(s)=\arg\max_a q_\pi(s,a)$.

What is policy iteration?::Alternating policy evaluation and policy improvement until convergence.

What is Generalized Policy Iteration (GPI)?::Any interleaving of policy evaluation and policy improvement, regardless of granularity.

What is value iteration?::Iterating Bellman optimality updates, combining evaluation and improvement in a single sweep.

Write the value iteration update.::$v_{k+1}(s)=\max_a\sum_{s',r}p(s',r\mid s,a)[r+\gamma v_k(s')]$.

What is the curse of dimensionality?::State spaces often grow exponentially with the number of state variables, making DP intractable.

What are the requirements for applying DP?::A complete and accurate probability model of the environment.

What is the computational complexity of DP?::Polynomial in the number of states (but the state count can be huge).
