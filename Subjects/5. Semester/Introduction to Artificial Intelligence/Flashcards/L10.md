# L10 - Reinforcement Learning - Temporal Difference Learning

## Flashcards

What are Monte Carlo (MC) methods in RL?::Model-free learning methods that learn values/policies from complete sample returns over episodes.

What is a key feature of MC methods?::They do not bootstrap; they use the entire rest of the episode's return.

What is "exploring starts" (ES)?::Ensuring every state-action pair has nonzero probability of being the starting pair in MC control.

What is an $\epsilon$-soft policy?::A policy where $\pi(a\mid s)>0$ for all actions, e.g., $\epsilon$-greedy, ensuring exploration.

What is off-policy learning?::Learning the value of a target policy from data generated by a different behavior policy.

What is importance sampling used for in off-policy MC?::Estimating the target policy's value using ratios of target/behavior probabilities.

What is bootstrapping?::Updating an estimate using other estimates (successor state values), as in DP and TD.

How do MC, DP, and TD compare on bootstrap/sampling?::MC: samples, no bootstrap. DP: sweeps, bootstraps. TD: samples, bootstraps.

What is TD(0) (simplest TD prediction)?::$V(S_t) \leftarrow V(S_t) + \alpha\,[R_{t+1}+\gamma V(S_{t+1})-V(S_t)]$.

What is the TD target?::$R_{t+1}+\gamma V(S_{t+1})$, an estimate of the return.

What is Sarsa?::On-policy TD control: $Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]$.

What is Q-learning?::Off-policy TD control: $Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma \max_a Q(S_{t+1},a)-Q(S_t,A_t)]$.

What is the difference between Sarsa and Q-learning?::Sarsa is on-policy (uses actual next action); Q-learning is off-policy (uses max over next actions).
