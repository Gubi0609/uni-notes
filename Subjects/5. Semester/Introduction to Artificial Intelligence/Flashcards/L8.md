# L8 - Reinforcement Learning - Dynamic Programming Examples

## Flashcards

What is the state-value function $v_\pi(s)$?::The expected return of starting in state $s$ and following policy $\pi$ thereafter: $v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$.

What is the action-value function $q_\pi(s,a)$?::The expected return of taking action $a$ in state $s$ and then following policy $\pi$: $q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t=s, A_t=a]$.

What is the optimal state-value function $v_*(s)$?::The maximum value achievable by any policy: $v_*(s) = \max_\pi v_\pi(s)$.

What is the optimal action-value function $q_*(s,a)$?::The expected return of taking action $a$ in state $s$ and thereafter following an optimal policy: $q_*(s,a) = \max_\pi q_\pi(s,a)$.

What is the discounted return $G_t$?::The sum of discounted future rewards: $G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}$.

What is a policy $\pi(a\mid s)$?::A mapping from states to probabilities of selecting each possible action.

Write the Bellman expectation equation for $v_\pi$.::$v_\pi(s) = \sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\bigl[r + \gamma v_\pi(s')\bigr]$.

Write the Bellman optimality equation for $v_*$.::$v_*(s) = \max_a \sum_{s',r} p(s',r\mid s,a)\bigl[r + \gamma v_*(s')\bigr]$.

What is policy evaluation?::Computing $v_\pi$ for a given policy $\pi$ by solving the Bellman equations (iteratively).

What is policy improvement ("greedification")?::Updating the policy to be greedy with respect to the current value function: $\pi'(s) = \arg\max_a q_\pi(s,a)$.

What is policy iteration?::Alternating between policy evaluation and policy improvement until convergence to the optimal policy.

What is Generalized Policy Iteration (GPI)?::Any interaction of policy evaluation and policy improvement, independent of their granularity.

What is value iteration?::Iterating Bellman optimality updates: $v_{k+1}(s) = \max_a \sum_{s',r} p(s',r\mid s,a)[r+\gamma v_k(s')]$, interleaving evaluation and improvement at every sweep.

What is the "curse of dimensionality" (Bellman)?::The number of states often grows exponentially with the number of state variables, making DP intractable for large problems.

What are the requirements for applying dynamic programming?::A complete and accurate probability model of the environment (transition dynamics $p$) and reward function.

What is the complexity of finding an optimal policy with DP?::Polynomial in the number of states (but the number of states can be astronomical).
