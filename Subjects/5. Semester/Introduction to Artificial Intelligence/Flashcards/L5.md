# L5 - Reinforcement Learning - Bandits

## Flashcards

What is reinforcement learning?::An agent learns through interaction with an environment, receiving rewards.

What is the k-armed bandit problem?::Choosing among $k$ actions, each with an unknown reward distribution, to maximize total reward.

What is exploration vs. exploitation?::Exploration tries actions to learn their values; exploitation prefers actions that appear best. You cannot do both simultaneously.

What is the greedy action at time $t$?::$A_t = \arg\max_a Q_t(a)$, the action with highest current estimate.

What is $\epsilon$-greedy action selection?::Usually pick the greedy action, but with probability $\epsilon$ pick a random action.

What is the sample-average estimate of action value?::$Q_t(a) = \frac{1}{N_t(a)}\sum_{i=1}^{N_t(a)} R_i$, averaging rewards received from action $a$.

What is the recency-weighted (exponential) update rule?::$Q_{n+1} = Q_n + \alpha\,(R_n - Q_n)$, with step-size $\alpha$.

What is the effect of $\alpha=1$ in the recency-weighted update?::Only the most recent reward matters (old estimates fully discarded).

What is optimistic initialization?::Initialize action values optimistically (e.g., $Q_1(a)=5$) to encourage exploration early.

What is UCB action selection?::Select the action maximizing $Q_t(a) + c\sqrt{\frac{\ln t}{N_t(a)}}$, balancing estimate and uncertainty.

What is the gradient bandit algorithm?::Maintains action preferences (not value estimates) and updates them via softmax probabilities.

What is the UniformBandit algorithm?::Pull each arm a fixed number $w$ times, then return the arm with the best average reward.

What is the bounded reward assumption?::Rewards lie in a bounded interval $[-r_{\max}, r_{\max}]$.
