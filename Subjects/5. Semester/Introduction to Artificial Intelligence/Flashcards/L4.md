# L4 - Fuzzy Logic Control 3

## Flashcards

What is a Mamdani (standard) fuzzy system?::A fuzzy inference system where both antecedents and consequents are fuzzy sets; output is obtained via defuzzification (e.g., centroid).

What is the main computational issue with Mamdani inference?::It requires integrating over a continuously varying function (centroid), which is not computationally efficient.

What is a Sugeno (TSK) fuzzy system?::A fuzzy system where rule consequents are crisp functions (usually polynomials) of the inputs: $b_i = g(x,y)$.

Write a typical Sugeno rule.::If $u_1$ is $A_1$ and $u_2$ is $A_2$ then $b_i = g(u_1,u_2)$.

Give an example of a first-order Sugeno rule.::$z = p_i x + q_i y + r_i$.

Name other fuzzy inference systems besides Mamdani and Sugeno.::Larsen, Tsukamoto, inverse Tsukamoto, hybrids.

What is input/output gain scaling?::Scaling inputs/outputs to spread membership functions by a factor, tuning controller sensitivity.

What is a t-norm?::A function $T:[0,1]^2\to[0,1]$ that is commutative, monotonic, associative, with identity 1; used for AND/conjunction.

Give examples of t-norms.::Minimum $\min(a,b)$, product $a\cdot b$, nilpotent minimum.

What is an s-norm (t-conorm)?::A function for OR/disjunction, commutative, monotonic, associative, with identity 0.

Give examples of s-norms.::Maximum $\max(a,b)$, algebraic sum $a+b-ab$, nilpotent maximum.

What is defuzzification?::Converting a fuzzy output set into a single crisp value.

List the parameters of a fuzzy controller.::Inputs/outputs, universe of discourse, membership functions, rule-base, t-norm/s-norm, defuzzification method, input/output gains.
